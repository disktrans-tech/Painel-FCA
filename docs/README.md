# Documentação de apoio

Esta pasta é opcional — use para registrar decisões e contexto que não
cabem no `README.md` principal e que não são óbvios só de ler o código.

## O que colocar aqui

- Decisões técnicas relevantes e o porquê (ex.: `decisao-nome-do-assunto.md`)
- Fluxos de negócio específicos do projeto (ex.: como funciona a troca de
  equipamento, regras de aprovação, integrações externas)
- Diagramas ou descrições de integração com outros sistemas

## O que NÃO colocar aqui

- Credencial, token ou dado real de cliente/colaborador
- Documentação que já existe em outro lugar (ex.: Swagger da API em
  `/docs`, ou o próprio README) — evite duplicar
- Rascunho de decisão ainda em aberto — só documente o que já foi decidido

Veja `decisao-exemplo.md` como modelo de estrutura para registrar uma
decisão técnica. Apague ou substitua esse arquivo pelo conteúdo real do
projeto.
