# Decisão: título curto da decisão

> Modelo de exemplo — apague ou substitua pelo conteúdo real do projeto.

| Campo | Valor |
|---|---|
| Data | *(aaaa-mm-dd)* |
| Autor(es) | *(nome)* |
| Status | proposta / decidida / revisada |

## Contexto

Qual problema ou dúvida motivou essa decisão? Que alternativas existiam?

## Decisão

O que foi decidido, em 1-2 frases diretas.

## Motivo

Por que essa opção e não outra — trade-offs considerados, restrição técnica
ou de negócio que pesou na escolha.

## Consequências

O que essa decisão implica para o resto do projeto (ex.: dependência nova,
limitação aceita, trabalho futuro necessário).
